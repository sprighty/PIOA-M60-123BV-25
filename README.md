# Что делает

Проект представляет собой простую учебную систему управления данными об автомобилях. В программе реализованы две версии базы данных: in-memory и файловая. In-memory вариант хранит данные в оперативной памяти и теряет их после завершения программы, а файловый вариант сохраняет данные в JSON-файл и позволяет использовать их между запусками.

При запуске пользователь выбирает тип базы данных, после чего может добавлять записи об автомобилях, просматривать все записи или искать их по фильтру. Каждая запись содержит car_id, brand, model, year и horsepower. В системе предусмотрены проверки корректности данных, включая уникальность ID, проверку структуры записи и валидацию значений года и мощности.

Запуск программы выполняется командой `python -m src.db` из корневой директории проекта. Для запуска тестов используется команда `python -m unittest discover tests`.

Проект демонстрирует различие между хранением данных в памяти и в файле JSON.
