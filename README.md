файлы __init__.py нужны, чтобы Python понимал что эта папка является пакетом.

программа разделена на:
- backend, где имеется файл memory.py, который выполняет функцию базы данных. В нём описан тип записи автомобиля CarRecord, который представляет собой кортеж из пяти элементов
- tui.py, где будет выполнен пользовательский интерфейс. После запуска пользователю отображается меню с доступными действиями: добавление записи, просмотр всех записей, поиск по фильтру и выход из программы.
- __main__.py, с которого будет запускаться программа

Основной функционал модуля реализован в функциях create_record() и select_record():
- create_record() для добавления новой записи, при неправильной записи года выпуска авто или повторяющегося id, будет выдана ошибка
- select_record() для поиска записей по одному или нескольким параметрам.

Чтобы запустить программу, необходимо открыть терминал в папке проекта и выполнить команду "python -m src.db"
